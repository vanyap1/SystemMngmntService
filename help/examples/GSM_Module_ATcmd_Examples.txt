2. ІНТЕРНЕТ-ЗАПИТ НА СЕРВЕР (TCP / HTTP GET)
Алгоритм активації GPRS-інтернету через класичний стек та відправка сирого HTTP-запиту на сервер із отриманням відповіді.
Частина А: Підняття GPRS-контексту
AT+QIMODE=0 — Переведення модема в режим даних за запитом (Normal Mode), щоб він не забивав UART «прозорою трубою».Відповідь: OK
AT+QIDNSIP=1 — Дозволити використання доменних імен (наприклад, google.com) замість прямих IP-адрес.Відповідь: OK
AT+QIDEACT — Примусове деактивування попередніх сесій для очищення стеку.Відповідь: DEACT OK
AT+CGATT=1 — Апаратне прикріплення модуля до пакетної мережі GPRS оператора.Відповідь: OK (Якщо ERROR — інтернет заблоковано оператором).
AT+QIREGAPP="internet" — Установка точки доступу (APN). Для всіх операторів України за замовчуванням — "internet".Відповідь: OK
AT+QIACT — Активація GPRS контексту та отримання локальної IP-адреси.Відповідь: OK
AT+QILOCIP — Перевірка поточної IP-адреси, яку модему виділив оператор (опціонально).Відповідь: 10.123.45.67 (приблизно)Частина Б: З'єднання та передача даних
AT+QIOPEN="TCP","httpbin.org",80 — Відкриття TCP-з'єднання з сервером на вказаний порт (80 — стандартний HTTP).Відповідь: OK і за мить: CONNECT OK
AT+QISEND — Переведення модема в режим готовності до відправки даних у відкритий TCP-канал.Відповідь: 
Модем видасть символ запрошення >
	Введення HTTP-запиту (копіювати і вставляти чітко як є, з порожнім рядком в кінці):
		PlaintextGET /ip HTTP/1.1
		Host: httpbin.org


Після введення порожнього рядка відправити керівний символ Ctrl+Z (HEX-байт 1A).
Частина В: Отримання відповіді від сервераПісля відправки модем видасть: SEND OK, 
а потім сповістить про прихід пакету від сервера:Повідомлення в UART: +QIURC: "recv",0
AT+QIRD=0,1024 — Команда на читання отриманих даних із буфера модема (канал 0, вичитати 1024 байти).Відповідь: Модем виведе сирий HTTP-текст відповіді від сервера:PlaintextHTTP/1.1 200 OK

Корисні команди для керування сесією:
ATH — Покласти трубку (якщо випадково ініційовано голосовий дзвінок командою ATD+380...;).
AT+QICLOSE — Закрити поточне TCP-з'єднання з сервером без падіння самого інтернету.
AT+QIDEACT — Повністю загасити інтернет-сесію GPRS (повернення в режим очікування).
