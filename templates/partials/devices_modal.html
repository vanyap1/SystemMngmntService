                                    Clone system → disk

                                

                                
Copies the running system onto another disk and makes it bootable. All data on the chosen disk is destroyed.
                                    The disk the system runs from cannot be chosen.

                                    

                                

                                

                                    

                                        
                                        

                                

                                
                                

                                

                                    

                                

                            

                        
                        

                            

                                Write image → disk

                            

                            
Writes an image (.img, .img.gz, .img.xz, .img.zst) from the SMB share, a mounted local disk (NAS)
                                or a home folder onto a whole disk. All data on the chosen disk is destroyed.
