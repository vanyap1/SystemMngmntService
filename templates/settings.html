Skip when archiving

One pattern per line, paths relative to the project directory. # starts a comment.

.git/folder .git at any depth, with everything inside
logs/*everything inside logs of the project root — the empty folder stays
data/cache/exactly this folder (a / inside = from the project root)
flash_dump.bina file (or folder) of this name at any depth
/notes.txtonly notes.txt in the project root
*.logby extension at any depth
images/*.pngby extension inside one folder (and its sub-folders)

Always left out: the backup directory and the panel itself if they lie inside the project, other mounted filesystems.

Keep on deploy

A deploy deletes the project directory and puts the archive's contents in its place. Files matching these patterns are copied from the current project into the new one first (they replace the archive's version) — local configs, credentials, databases, calibration data.

/config.jsonthe config file in the project root
settings/*.iniall .ini files of settings
data/the whole data folder
.git/keep the git history of the current project (otherwise a deploy replaces it with the archive's)
*.dbevery database file at any depth

Same syntax as above. Order of a deploy: optional full backup (skip patterns not applied) → extract to a temporary folder next to the project → stop the service → copy the kept files → swap the folders → start the service → delete the old folder. Any failure before the swap leaves the project untouched.
